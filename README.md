# whale-pet-android-hd
泡泡鲸安卓手机 清晰版：离线桌宠，106 段透明动画
泡泡鲸 Android 清晰版

**点击主页绿色按钮下载zip文件**
应该会得到应该apk文件，下载后再浏览器打开就会下载了

- 106 段透明桌宠动画已进行清晰化处理
- 支持 Android 9 及以上系统
- 独立包名，可以和原版同时安装
- 首次安装时，请允许悬浮窗权限
- 如需让桌宠长期运行，请关闭系统对本应用的电池优化

本版本基于开源项目修改：
https://github.com/duoxichangan/whale-pet-Android

角色动画来源：
https://github.com/PC2005-cloud/dsh-pet
